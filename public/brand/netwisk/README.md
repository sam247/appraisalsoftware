# Netwisk brand

Umbrella brand for Disclosurely and Appraisal Software. **Wordmark only — no icon.**

- Lowercase **netwisk**, Inter Bold, tracking −4.5%.
- The dot of the **i** is replaced by a small jade "whisk" stroke, centred over the stem at tittle height.
- Jade `#1f9d63` on light backgrounds, `#2fbf7a` on dark.

Files: `wordmark.svg` (ink), `wordmark-white.svg` (dark backgrounds). These set the word as live text in Inter —
for print or partner use, have a designer outline the text, and check the stroke position against the rendered `ı`.

In code: `NetwiskLogo` from `src/components/brand/NetwiskLogo.tsx` (inherits `currentColor`).
