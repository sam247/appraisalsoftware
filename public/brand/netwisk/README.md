# Netwisk brand files

Umbrella brand for Disclosurely and Appraisal Software.

- `mark.svg` — connected-N mark, ink with jade node (light backgrounds)
- `mark-white.svg` — for dark backgrounds
- `app-icon.svg` — dark rounded tile, matches the Appraisal Software "a." icon

Wordmark: lowercase **netwisk**, Inter Bold, tracking −3%, set beside the mark at ~0.93× the mark height.
In code use `NetwiskLogo` / `NetwiskMark` from `src/components/brand/NetwiskLogo.tsx` (inherits `currentColor`).
