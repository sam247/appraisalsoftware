# Marketplace sources register

What each sector pack is designed to support, the primary sources behind it, and when they were last checked. Update this file in every marketplace PR, and bump a pack's `reviewed` date (and `version` if questions change) when its sources are re-checked.

Positioning rule: packs **support** an organisation's own processes. They never claim compliance, approval or endorsement (enforced in `src/lib/marketplace.test.ts`). Every sector pack shows `REGULATORY_DISCLAIMER`.

Status key: **Verified** = checked against the primary source; **Partly** = primary source checked, our wording adjusted; **Sign-off** = human reviewer has approved the pack's wording.
