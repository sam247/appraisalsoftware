# appraisalsoftware.co.uk Historical Domain Record

## Why this exists

The domain **appraisalsoftware.co.uk** was previously used for substantially the same topic as the current Disclosurely-owned product: **employee appraisal software**, **employee performance management**, and **360-degree feedback**.

The historical product/brand was primarily **emPerform**, and the site itself was branded and described as **Employee Appraisal Software**.

The current site was relaunched on **12 August 2026** as **Appraisal Software by Disclosurely**.

This document preserves domain history and a captured historical URL corpus so we can make **evidence-based** decisions later about content restoration, redirects, backlink reclamation, and topical architecture.

**This historical information must NOT be interpreted as an instruction to recreate the old site.**

## Redirect policy

> **DO NOT blanket 301 historical URLs to the homepage.**

A historical URL should **only** receive a redirect when **all** of the following are true:

1. We have created a **genuinely equivalent** current page; **and**
2. The historical URL's topic **closely matches** that page; **and**
3. Redirecting it makes sense for **users**; **and**
4. Preferably, backlink/history data indicates the old URL is **worth reclaiming**.

Until then, historical URLs can remain **404**.

- Do **not** recreate pages solely because they existed historically.
- Do **not** redirect unrelated historical content to `/`.

---

## Future restoration workflow

Before restoring or redirecting any historical URL:

1. Check **current keyword demand**.
2. Check **current SERP intent**.
3. Check **historical Wayback content** where available.
4. Check **backlinks/referring domains** to that specific historical URL.
5. Confirm **Disclosurely genuinely supports** any product claims involved.
6. Decide whether the topic deserves:
   - a commercial page
   - feature page
   - resource/guide
   - redirect to an existing equivalent
   - or **no restoration**
